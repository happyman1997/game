# Reels Maker

Конвейер для Instagram Reels и TikTok: сам делает вертикальные ролики 1080×1920 и выкладывает их по расписанию через официальные API.

| файл | что делает |
|------|------------|
| `make_fakegame.py` | ролики про несуществующие игры: «найденная кассета», реклама мобилки, трейлер, патч-ноты |
| `make_absurd.py` | генерирует абсурдные ролики с нуля: картинку, персонажей, музыку и смех |
| `make_reels.py` | собирает ролики-реакции из ваших клипов: смеющийся человек и закадровый смех |
| `upload.py` | заливает готовые ролики в Instagram и TikTok |
| `autopilot.py` | держит запас роликов и выкладывает их в заданное время |

Нужны Python 3.9+ и ffmpeg. Сторонние библиотеки не нужны.

- Windows: `winget install Gyan.FFmpeg`, затем перезапустить терминал
- macOS: `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg`

Быстрый старт:

```bash
python make_fakegame.py --count 3              # три ролика про несуществующие игры в output/
cp config.example.json config.json             # на Windows: copy config.example.json config.json
python upload.py check                         # после заполнения config.json
python autopilot.py                            # работать постоянно
```

## 0. Несуществующие игры (`make_fakegame.py`)

Форматы выбраны по исследованию трендов: [research/fake-games-trend-brief.md](research/fake-games-trend-brief.md).

| формат | что в ролике |
|--------|--------------|
| `lost` | «найденная VHS»: заставка выдуманной консоли, титульный экран, пиксельный платформер (герой сам бегает, прыгает, собирает предметы, топчет врагов, говорит странное в диалоговом окне), иногда GAME OVER. Эффект старой кассеты |
| `ad` | пародия на рекламу мобильной игры: «99% FAIL!», рука вытаскивает не тот штифт, лава сыплется на героя, FAIL, вторая попытка с абсурдным финалом, карточка «PLAY NOW» |
| `trailer` | трейлер: студия, «от создателей …», нарезка геймплея под «бум», обещания со звёздочкой («OPEN WORLD*» → «*ONE ROOM»), название, «COMING …» |
| `patch` | патч-ноты к уже показанной игре, текст печатается на экране — зрители ставят на паузу, чтобы дочитать |

Пиксельная графика рисуется на холсте 270×480 и растягивается до 1080×1920 без размытия. Chiptune-музыка и звуки (прыжок, монетка, «вжух», провал, смех) синтезируются и привязаны к событиям в кадре.

Все игры складываются во «вселенную» `state/fakegames.json`. Патч-ноты выходят к уже показанным играм, у трейлеров бывают продолжения с растущим номером (Goose Racing 64 → 65), у студий — «прошлые работы». Это даёт сериальность, как у Bird Game 3. Консоли, студии и игры выдуманы. В тексте каждого поста написано «This game does not exist».

```bash
python make_fakegame.py                          # формат выбирается сам
python make_fakegame.py --format ad --count 3    # три рекламы
python make_fakegame.py --weights lost=3,ad=2,patch=1,trailer=1   # свои доли форматов
```

## 1. Абсурдные ролики (`make_absurd.py`)

Каждый ролик собирается из случайных сцен, нарезанных в такт синтезированной музыке:

- **фоны**: фрактал Мандельброта с приближением, игра «Жизнь», клеточные автоматы, плазма, шахматка, градиенты, треугольник Серпинского, телевизионные таблицы;
- **эффекты**: вращение цвета, негатив, тряска, пульсация в бит, зеркало, пиксели, шлейфы, «пережаренные» цвета, сдвиг каналов;
- **персонажи**: квадратные и круглые рожицы, которые ржут, бегают глазами, прыгают в такт и качаются;
- **текст**: подпись-мем сверху («cactus speedrun (any%)», «nobody: the microwave at 3am:») и выкрики посередине («BRUH», «404»);
- **звук**: бит, бас, писклявая мелодия, «бум» на каждой склейке, синтетический смех, «боинги» и «пи-и-и». Всё синтезируется в коде.

Всё в ролике сгенерировано, чужого контента нет, поэтому нет и вопросов об авторских правах.

```bash
python make_absurd.py                      # один ролик
python make_absurd.py --count 10           # десять
python make_absurd.py --seed 42            # повторить ролик с тем же зерном (зерно пишется в .json)
python make_absurd.py --min-dur 61 --max-dur 75   # длиннее минуты (требование TikTok Creator Rewards)
python make_absurd.py --no-flash           # без вспышек-негативов на склейках
```

**Свои подписи и выкрики.** Создайте `captions.txt` (одна подпись на строку, `\n` — перенос строки) и/или `words.txt` (один выкрик на строку). Ваши подписи будут выпадать в 70 % случаев, в остальных — сгенерированные. Строки, начинающиеся с `#`, считаются комментариями.

На Windows для подписей берётся Impact, если его нет — Arial Bold. Свой шрифт задаётся через `--font` или кладётся в папку `fonts/`.

## 2. Ролики-реакции (`make_reels.py`)

1. Клип вписывается в кадр поверх своей же размытой копии.
2. Поверх накладывается видео смеющегося человека. Зелёный или синий фон вырезается автоматически.
3. Закадровый смех вставляется в момент кульминации: скрипт ищет самый резкий всплеск громкости. Момент можно задать и вручную.
4. В конце последний кадр держится 1,5 с, чтобы смех доиграл.
5. Сверху пишется подпись, под клипом — автор и лицензия.

```
input/              исходные клипы (mp4, mov, webm…)
assets/reactions/   видео смеющегося человека, лучше на зелёном фоне
assets/laughs/      звуки смеха (mp3, wav…)
sources.csv         автор, лицензия и ссылка для каждого клипа (образец: sources.example.csv)
```

| колонка в sources.csv | что писать |
|-----------------------|------------|
| file      | имя файла в `input/` |
| url       | ссылка на оригинал |
| author    | автор или канал |
| license   | `CC BY 4.0`, `с разрешения автора` и т. п. |
| caption   | подпись сверху ролика и первая строка поста |
| laugh_at  | секунды, когда смеяться, например `4.5 11`. Пусто — скрипт найдёт сам |

```bash
python make_reels.py                    # собрать всё новое из input/
python make_reels.py --require-credit   # пропускать клипы без автора
python make_reels.py --help             # все настройки
```

**Где брать клипы законно.** В поиске YouTube: «Фильтры» → «Особенности» → «Creative Commons». Такие ролики (лицензия «с указанием авторства») можно перерабатывать и монетизировать, если указать автора. Другой вариант — письменное разрешение автора. Чужие ролики без спроса площадки в ЕС отлавливают при загрузке, и аккаунт со временем блокируют.

**Реакция.** Лучше всего снять себя на зелёном фоне. Подойдут и стоковые видео с бесплатной лицензией, например с Pexels или Pixabay. **Смех** — звуки с лицензией CC0 или CC BY с Pixabay или Freesound.

## 3. Заливка (`upload.py`)

Скопируйте `config.example.json` в `config.json`. Этот файл в git не попадает: в нём ключи. Токены и история публикаций хранятся в `state/` и тоже не коммитятся.

```bash
python upload.py check             # проверить доступы, подсказать ID аккаунта
python upload.py tiktok-login      # один раз войти в TikTok через браузер
python upload.py post              # выложить следующий ролик на все включённые площадки
python upload.py post --dry-run    # показать, что будет выложено, ничего не отправляя
python upload.py status            # очередь, ошибки, черновики TikTok
```

Ролики выкладываются по порядку, от старых к новым. Площадки ведутся независимо: если Instagram упал, TikTok продолжит. Если площадка трижды отклонила ролик, он пропускается. Ошибки доступа (просроченный токен, лимит, нет сети) попыткой не считаются, ролик ждёт, пока доступ не починят.

### Instagram

Нужен профессиональный аккаунт: в приложении Instagram «Настройки» → «Тип аккаунта и инструменты» → переключиться на аккаунт автора или бизнес-аккаунт.

**Режим `"mode": "local"` (по умолчанию).** Файл загружается прямо с компьютера, хостинг не нужен. Нужен вход через Facebook:

1. Создайте страницу Facebook (любую) и привяжите к ней Instagram-аккаунт.
2. На [developers.facebook.com](https://developers.facebook.com/apps) создайте приложение типа «Business» и добавьте продукт Instagram с настройкой через Facebook Login.
3. В [Graph API Explorer](https://developers.facebook.com/tools/explorer/) выберите приложение и получите User Token с правами `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`, `business_management`.
4. В [Access Token Debugger](https://developers.facebook.com/tools/debug/accesstoken/) нажмите «Extend Access Token», чтобы токен жил 60 дней.
5. Впишите токен в `instagram.access_token` и включите `"enabled": true`.
6. Запустите `python upload.py check`. Он покажет `ig_user_id`, впишите его в config.json.

Пока приложение в режиме разработки, оно работает с аккаунтами его администраторов, то есть с вашим, без проверки Meta. Токен живёт 60 дней: `check` показывает, сколько осталось. Когда срок подходит к концу, повторите шаги 3–4.

**Режим `"mode": "url"`.** Вход через Instagram, страница Facebook не нужна, токен продлевается автоматически. Но Instagram скачивает ролик сам, поэтому папка `output/` должна быть доступна в интернете по адресу `public_base_url` (например, бакет Cloudflare R2 или S3 с синхронизацией).

Лимит Instagram: 100 публикаций через API за сутки.

### TikTok

1. На [developers.tiktok.com](https://developers.tiktok.com/) создайте приложение с платформой **Desktop**.
2. Добавьте продукты **Login Kit** и **Content Posting API**.
3. В Login Kit добавьте Redirect URI `http://localhost:3455/callback/`.
4. Права (scopes): `user.info.basic`, `video.upload`, для прямой публикации ещё `video.publish`.
5. Для начала включите Sandbox и добавьте свой TikTok-аккаунт в тестовые пользователи. Для постоянной работы отправьте приложение на проверку TikTok.
6. Впишите Client key и Client secret в config.json, включите `"enabled": true`.
7. Запустите `python upload.py tiktok-login`: откроется браузер, разрешите доступ.

Дальше вход обновляется сам. Повторный вход нужен раз в 180 дней.

Режимы TikTok:

- `"mode": "inbox"` (по умолчанию). Ролик приходит в приложение TikTok уведомлением-черновиком. Вы открываете его и публикуете одним нажатием; подпись `upload.py` печатает и показывает в `status`. Ограничение TikTok: не больше 5 неопубликованных черновиков за сутки.
- `"mode": "direct"`. Ролик публикуется сразу. Пока приложение не прошло аудит TikTok, такие ролики видны только вам (SELF_ONLY).

## 4. Автопилот (`autopilot.py`)

```bash
python autopilot.py          # работать постоянно, окно должно быть открыто
python autopilot.py --once   # один раз: сделать ролик, если очередь пуста, и выложить
```

Настройки — в разделе `"autopilot"` файла config.json:

| ключ | что значит |
|------|------------|
| `post_times` | время публикаций по часам компьютера, например `["11:40", "16:20", "20:50"]` |
| `jitter_minutes` | случайный сдвиг каждого времени ± минут, чтобы публикации не шли минута в минуту |
| `source` | `fakegame` — несуществующие игры, `absurd` — абсурд, `mix` — 70 % игр и 30 % абсурда, `reels` — клипы из `input/`, `both` — сначала клипы, потом абсурд |
| `min_queue` | сколько готовых роликов держать про запас |
| `fakegame_args`, `absurd_args`, `reels_args` | дополнительные параметры для генераторов, например `["--weights", "lost=3,ad=2"]` |

Если компьютер был выключен и время публикации прошло больше двух часов назад, этот слот пропускается: автопилот не выкладывает пачку роликов сразу после включения.

**Без открытого окна (Windows).** В «Планировщике заданий» создайте задачу на нужное время: программа `python`, аргументы `autopilot.py --once`, рабочая папка — эта папка. На Linux или VPS то же самое делается через cron.

## Советы

- Начните с 1–3 роликов в день. Частые однотипные публикации платформы обычно показывают хуже.
- Следите за `python upload.py status`: там видно, что отклонено и почему.
- TikTok Creator Rewards платит только за ролики длиннее минуты и не во всех странах. Проверьте в TikTok Studio, доступна ли программа для вашего аккаунта. Для неё генератор запускается с `--min-dur 61 --max-dur 75`.
