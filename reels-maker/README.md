# Reels Maker

Собирает вертикальные ролики-реакции (1080×1920) для Instagram Reels и TikTok:

1. Клип вписывается в кадр поверх своей же размытой копии. Горизонтальный клип ставится в центр, вертикальный растягивается на весь экран.
2. Поверх накладывается видео смеющегося человека. Зелёный или синий фон вырезается автоматически, без него реакция идёт в белой рамке.
3. Закадровый смех вставляется в момент кульминации: скрипт ищет самый резкий всплеск громкости (удар, крик, падение). Момент можно задать и вручную.
4. В конце последний кадр держится 1,5 с, чтобы смех доиграл.
5. Сверху пишется подпись, под клипом — автор и лицензия.
6. Рядом с роликом кладётся `.json` с готовым текстом поста для будущей автозаливки.

## Установка

Нужны Python 3.9+ и ffmpeg. Сторонние библиотеки не нужны.

- Windows: `winget install Gyan.FFmpeg`, затем перезапустить терминал
- macOS: `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg`

## Папки

```
reels-maker/
  input/              исходные клипы (mp4, mov, webm…)
  assets/reactions/   видео смеющегося человека, лучше на зелёном фоне
  assets/laughs/      звуки смеха (mp3, wav…)
  sources.csv         автор, лицензия и ссылка для каждого клипа
  output/             готовые ролики и .json к ним
  fonts/              (необязательно) свой .ttf для подписей
```

Реакция и смех для каждого ролика выбираются случайно из своих папок. Чем больше вариантов там лежит, тем меньше ролики похожи друг на друга.

## sources.csv

Скопируйте `sources.example.csv` в `sources.csv`. Файл можно редактировать в Excel, разделитель `;` или `,`.

| колонка   | что писать |
|-----------|------------|
| file      | имя файла в `input/` |
| url       | ссылка на оригинал |
| author    | автор или канал. Без него подписи об источнике не будет |
| license   | `CC BY 4.0`, `с разрешения автора` и т. п. |
| caption   | подпись сверху ролика и первая строка поста |
| laugh_at  | секунды, когда смеяться, например `4.5 11`. Пусто — скрипт найдёт сам |

## Запуск

```bash
python make_reels.py                       # собрать всё новое из input/
python make_reels.py --require-credit      # пропускать клипы без автора
python make_reels.py --watch 300           # работать постоянно, проверять input/ каждые 5 минут
python make_reels.py --hashtags "#funny #fail #lol"
python make_reels.py --help                # все настройки
```

Готовые ролики повторно не собираются. Чтобы пересобрать, добавьте `--overwrite`.

Полезные настройки:

- `--reaction-pos below|bl|br|tl|tr` — где стоит реакция. По умолчанию под горизонтальным клипом или в левом нижнем углу вертикального.
- `--reaction-show laugh` — реакция появляется только с началом смеха.
- `--laugh-volume 0.5`, `--clip-volume 1.0` — баланс громкости.
- `--similarity 0.2` — вырезать фон сильнее, если по краям человека остаётся зелень.

## Проверка без настоящих роликов

```bash
python make_demo_assets.py demo
python make_reels.py --input demo/input --reactions demo/reactions --laughs-dir demo/laughs --sources demo/sources.csv --output demo/output
```

## Где брать материал законно

Instagram и TikTok в ЕС обязаны отлавливать чужой контент при загрузке. Ролики, скачанные без спроса, ловят жалобы, теряют охваты, а аккаунт в итоге блокируют.

**Клипы**

- В поиске YouTube: «Фильтры» → «Особенности» → «Creative Commons». У ролика под описанием должно стоять «Лицензия Creative Commons — с указанием авторства». Такие ролики можно перерабатывать и монетизировать, если указать автора. Это `author` и `license` в `sources.csv`.
- Разрешение автора. Напишите ему, предложите указать авторство и ссылку. Сохраните скриншот ответа.
- Свои съёмки или ролики, присланные подписчиками с согласием.

**Реакция.** Лучше всего снять себя на зелёном фоне: зелёная ткань и телефон. Это добавляет оригинальности, и алгоритмы реже помечают ролик как перезалив. Подойдут и стоковые видео с бесплатной лицензией, например с Pexels или Pixabay. Проверьте, что лицензия разрешает изменения.

**Смех.** Звуки с лицензией CC0 или CC BY с Pixabay или Freesound. Для CC BY указывайте автора в тексте поста.

## Требования платформ

- Готовый ролик соответствует требованиям Reels и TikTok: H.264, AAC 48 кГц, 30 к/с, 9:16.
- TikTok Creator Rewards платит только за ролики длиннее минуты и не во всех странах. Проверьте в TikTok Studio, доступна ли программа для вашего аккаунта.
- Если клип длиннее `--max-duration` (170 с), он обрезается.
