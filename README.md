# 👑 Корона и Династия

Браузерная grand strategy в духе **Crusader Kings 3**: вы управляете не страной,
а династией — женитесь, интригуете, воюете, передаёте титулы наследникам и
пытаетесь не дать роду угаснуть. Главная особенность — **предельная модульность**:
вся игра, включая базовый контент, состоит из модов, которые описываются
простыми YAML-файлами, а при необходимости дополняются JavaScript.

Стартовая эпоха — **1066 год, Норманнское завоевание**: Британские острова и
Франция, ~150 графств, около 90 исторических персонажей (Вильгельм Нормандский,
Гарольд Годвинсон, Малькольм III, Филипп I, Бодуэн Фландрский, ирландские и
валлийские короли…).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка статической версии: `npm run build` (результат — в `dist/`).

## Что есть в игре

- **Персонажи** с навыками, чертами характера, образованием, врождёнными
  чертами (наследуются!), здоровьем, стрессом, генетикой внешности и
  процедурными портретами.
- **Династии и наследование**: разделённое наследование, первородство,
  таниство; браки, беременность, дети, совершеннолетие, смерть от старости,
  болезней, в бою и от рук убийц. Когда ваш персонаж умирает, вы продолжаете
  играть за наследника.
- **Феодальная иерархия**: графства → герцогства → королевства → империи,
  вассалы и сюзерены, создание и узурпация титулов, лимит домена, процедурные гербы.
- **Образ жизни**: пять образов жизни (дипломатия, воинское дело, управление,
  интриги, учёность), 15 фокусов и 40 перков в деревьях; завершённое дерево
  даёт черту — «Дипломат», «Стратег», «Зодчий», «Интриган»…
- **Совет**: канцлер, казначей, маршал, тайный советник и духовник с задачами —
  от сбора податей и муштры ополчения до раскрытия заговоров и поиска претензий.
- **Темница**: заключение (с законным поводом или ценой тирании), выкуп, казнь,
  побеги; правителей берут в плен при взятии столиц и после проигранных битв.
- **Фракции вассалов**: за независимость и за претендента; недовольство,
  ультиматумы и мятежи; новые правители поначалу не пользуются доверием.
- **Профессиональные войска**: пехота, лучники, пикинёры, конница, рыцари и
  культурные отряды (хускарлы, шевалье, галлогласы, валлийские лучники) с
  контрами и бонусами местности.
- **Экономика**: налоги и ополчение графств, развитие, постройки, доход от вассалов.
- **Война**: поводы к войне (претензии, де-юре, независимость, набеги,
  священная война), союзники через браки, армии на карте, сражения с учётом
  местности и полководцев, осады и оккупация, счёт войны, перемирия.
- **Дипломатия и интриги**: браки, союзы, подарки, вассализация, пожалование и
  отзыв титулов, приглашение ко двору; интриги — убийство, соблазнение, дружба,
  расположение, фабрикация претензий — с шансами успеха и раскрытия.
- **События и решения**: болезни, стресс и его срывы, жизнь двора, семья,
  пиры, охота, паломничества, комета 1066 года, вторжение в Англию,
  объединение Британии.
- **ИИ**: правители воюют, женят детей, строят, интригуют, заключают мир.
- **Карта** с рельефом, режимами (державы, дипломатия, де-юре, культуры,
  веры, местность, развитие, доход и режимы из модов), подписями держав и армиями.
- **Сохранения** (в браузере и в файл), автосохранение каждый год.
- **Два языка** — русский и английский (переключаются в меню).

### Управление

| Действие | Как |
|---|---|
| Пауза / продолжить | Пробел или кнопка ▶ |
| Скорость | Клавиши 1–5 |
| Выбрать провинцию / армию | Левый клик по карте |
| Отправить армию | Выбрать армию, правый клик по провинции |
| Перемещение карты | Перетаскивание мышью, колесо — масштаб |
| Быстрое сохранение | F5 |
| Закрыть окно | Esc |

## Моды

```
mods/
  core/                 ← базовая игра — тоже мод
  tournaments/          ← пример мода без кода (только YAML)
  plague/               ← пример JS-мода: эпидемии, своя система и интерфейс
  elective_monarchy/    ← пример расширения реестров: новый закон наследования
```

Мод — это папка с `mod.json`, данными (`data/*.yaml`), переводами
(`localization/<язык>/*.yaml`) и, по желанию, JS-скриптами. Данные модов
**сливаются**: мод может изменить одно поле чужой черты, дописать событие в
чужой on_action или удалить решение — не копируя чужие файлы:

```yaml
traits:
  brave:
    modifiers: { prowess: 4 }          # остальное у «Храброго» не меняется
on_actions:
  on_monthly_pulse:
    random_events:
      events: { my_mod.0001: 10 }      # своё событие в общий пул
decisions:
  seek_solitude: { $delete: true }     # убрать решение
```

Логика пишется на встроенном скриптовом языке (в стиле Paradox):

```yaml
decisions:
  hold_tournament:
    is_shown: { is_ruler: yes, tier: ">= duchy" }
    is_valid: { is_at_war: no }
    cost: { gold: { value: 60, add: { value: tier, multiply: 20 } } }
    effect:
      - random_list:
          - { weight: 60, add_prestige: 100, add_trait: tourney_champion }
          - { weight: 40, add_trait: wounded }
```

А JS-моды получают API для всего остального — систем симуляции, новых
триггеров и эффектов, алгоритмов наследования, режимов карты, панелей интерфейса:

```js
export function init(api) {
  api.systems.add({ id: 'my_system', order: 100, onMonth(game) { /* ... */ } });
  api.script.effect('my_effect', { apply(ctx, scope, arg) { /* ... */ } });
  api.ui.mapModes.register('my_mode', { id: 'my_mode', name: 'Мой режим', color: (game, prov) => '#a33' });
}
```

📘 **Подробное руководство: [`docs/MODDING.md`](docs/MODDING.md)**
📗 Справочник всех триггеров, эффектов и значений: [`docs/SCRIPT_REFERENCE.md`](docs/SCRIPT_REFERENCE.md)
📙 Заготовка мода: [`docs/mod-template`](docs/mod-template)

Инструменты моддера:

```bash
npm run validate                      # проверить моды (синтаксис, ссылки, скрипты, закладки)
npm run sim -- --years 50 --verbose   # прогнать мир без игрока и посмотреть статистику
npm run docs:script                   # пересобрать справочник скриптового языка
npx tsx tools/render-map.ts out.png   # нарисовать растр провинций
```

## Архитектура

```
src/
  engine/                 движок без зависимостей от браузера (работает и в Node)
    core/                 даты, RNG, хуки, реестры, слияние, форматы, локализация, шум
    mods/                 манифест, источники модов (сборка / папка / Node / память), загрузчик
    content/              хранилище контента, нормализация, валидация
    script/               скриптовый язык: интерпретатор, реестры, встроенная библиотека
    map/                  построение растровой карты из «зёрен» провинций
    world/                логика мира: персонажи, титулы, экономика, наследование,
                          войны, армии, интриги, события, решения, взаимодействия, ИИ
    features/             механики: образ жизни, совет, темница, фракции, отряды
                          (каждую можно отключить из данных: defines.disabled_features)
    systems/              системы симуляции (экономика, демография, события, война, ИИ…)
    engine.ts             Engine: моды + контент + реестры; создаёт партии
    game.ts               Game: состояние партии (чистый JSON) + время
    api.ts                API для JS-модов
  ui/                     браузерный интерфейс (canvas-карта, панели, окна, меню)
  locale/                 встроенные строки движка и интерфейса (ru, en)
mods/                     моды (см. выше)
tests/                    автотесты (vitest)
tools/                    CLI: симуляция, валидатор, генератор документации, рендер карты
docs/                     руководство моддера, справочник, шаблон мода
```

Ключевые идеи:

- **Механики — подключаемые модули.** Образ жизни, совет, темница, фракции и
  профессиональные войска устанавливаются в движок так же, как JS-моды: своими
  системами, триггерами и хуками. Любую можно выключить одной строкой в данных,
  а мод может добавить свою (`api.features.add`).
- **Всё расширяемое — реестры.** Триггеры, эффекты, значения, ссылки на
  скоупы, системы симуляции, алгоритмы наследования, цели войн, поставщики
  модификаторов и мнения, режимы карты, панели — регистрируются одинаково и
  движком, и модами; любой элемент можно заменить.
- **Состояние — чистый JSON.** Сохранение = `JSON.stringify(state)`; моды хранят
  свои данные в `game.modData()`.
- **Детерминированность.** Генератор случайных чисел хранится в состоянии:
  одинаковое сохранение даёт одинаковое будущее.
- **Изоляция ошибок.** Ошибка в хуке, системе или скрипте мода не роняет игру —
  она попадает в список проблем модов (меню → «Проблемы модов»).

## English summary

**Crown & Dynasty** is a moddable browser grand strategy inspired by Crusader
Kings 3 (characters, dynasties, succession, feudal titles, wars, schemes,
events, lifestyles and perks, councils, prisoners, vassal factions,
men-at-arms, AI) set in 1066 Britain and France. *Everything* — including the base
game — is a mod: YAML data with a Paradox-style scripting language, plus an
optional JavaScript API for new systems and UI. Run with `npm install && npm run dev`.
See `docs/MODDING.md` (in Russian) and the example mods in `mods/`.
